# Como colaborar — Grupo 6

1. Atualize sua cópia da branch principal antes de começar.
2. Crie uma branch para uma tarefa específica.
3. Faça alterações pequenas e relacionadas à tarefa.
4. Teste a página no navegador.
5. Registre as alterações com um commit de mensagem clara.
6. Envie a branch ao GitHub.
7. Abra um Pull Request para a branch `main`.
8. Aguarde a revisão de outro integrante e faça os ajustes solicitados.
9. Após aprovação, integre o Pull Request à `main`.

## Padrão sugerido para nomes de branches

- `feature/catalogo`: alterações no catálogo.
- `feature/filtros`: pesquisa e filtros.
- `feature/formulario`: formulário de sugestões.
- `style/responsividade`: ajustes visuais e responsivos.
- `docs/documentacao`: documentação do projeto.

## Exemplos de mensagens de commit

- `feat: adiciona cards ao catálogo cultural`
- `feat: implementa pesquisa e filtro por categoria`
- `style: ajusta layout para dispositivos móveis`
- `docs: adiciona documentação do projeto`
- `fix: corrige caminho das imagens`

Os nomes são sugestões de organização para o grupo. A equipe pode adaptá-los conforme a divisão real das tarefas.
