# Relatório final — Cultura Viva

**Disciplina:** Desenvolvimento Front-end para Web  
**Avaliação:** A2 — Projeto em Grupo  
**Grupo:** 6  
**Tema:** Catálogo Cultural Colaborativo

## 1. Introdução.

O projeto Cultura Viva consiste em um catálogo cultural colaborativo desenvolvido para apresentar conteúdos de diferentes áreas, como literatura, cinema, música e arte. A página busca organizar indicações culturais de maneira visual e facilitar a descoberta de novos conteúdos.

## 2. Desenvolvimento da página

A estrutura foi criada com HTML5, utilizando áreas de cabeçalho, navegação, conteúdo principal, seções e rodapé. O CSS externo foi utilizado para definir cores, espaçamentos, tipografia, cards e adaptação do layout para diferentes tamanhos de tela.

O JavaScript é responsável por montar os cards do catálogo, realizar a pesquisa por texto, filtrar os conteúdos por categoria e apresentar uma mensagem de confirmação após o preenchimento do formulário.

As imagens utilizadas estão organizadas na pasta `img`, enquanto os arquivos de estilo e comportamento estão separados nas pastas `css` e `js`.

## 3. Uso de Git e GitHub

O controle de versões com Git permite acompanhar as modificações realizadas nos arquivos e manter um histórico do desenvolvimento. O GitHub permite armazenar o repositório remotamente e facilitar a colaboração entre os integrantes.

Para organizar o trabalho em grupo, foi proposto o uso de branches para separar as tarefas. Após realizar e testar uma alteração, o integrante envia sua branch ao GitHub e abre um Pull Request. Esse pedido permite que outro integrante revise o código antes da integração à branch principal.

## 4. Organização e colaboração

A separação dos arquivos em HTML, CSS, JavaScript, imagens e documentação facilita a manutenção do projeto. O fluxo de branches e Pull Requests ajuda a evitar alterações diretas e desorganizadas na versão principal e permite que a equipe acompanhe as contribuições.

## 5. Considerações finais

O desenvolvimento do Cultura Viva reúne os conhecimentos de construção de páginas web e os conceitos de colaboração com Git e GitHub indicados para o Projeto 6. A proposta permite praticar a organização de arquivos, o controle de versões, o trabalho com branches e a revisão de alterações por Pull Requests.
