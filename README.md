# Cultura Viva — Catálogo Cultural Colaborativo

**Disciplina:** Desenvolvimento Front-end para Web  
**Avaliação:** A2 — Projeto em Grupo  
**Grupo:** 6  
**Tema:** Catálogo Cultural Colaborativo

## 1. Apresentação

O Cultura Viva é uma página web criada para reunir e apresentar indicações culturais, como livros, filmes, músicas, arte, teatro, museus e outros conteúdos. A proposta é permitir que visitantes explorem o catálogo e enviem sugestões para colaborar com a divulgação cultural.

## 2. Objetivo

Desenvolver um catálogo cultural colaborativo e utilizar o Git e o GitHub para organizar o trabalho em equipe, controlar versões do código e integrar alterações por meio de branches e Pull Requests.

## 3. Tecnologias e recursos

- HTML5: estrutura e conteúdo da página.
- CSS3: identidade visual e adaptação para telas menores.
- JavaScript: pesquisa, filtro por categoria e interação do formulário.
- Git: controle de versões do projeto.
- GitHub: repositório remoto e colaboração da equipe.
- Imagens locais: arquivos armazenados na pasta `img/`.

## 4. Funcionalidades

- Navegação entre as seções Início, Catálogo, Sobre e Colabore.
- Exibição de cards culturais com imagem, categoria, título e descrição.
- Pesquisa de conteúdo pelo texto.
- Filtro por categoria.
- Formulário para registrar uma sugestão na demonstração local.
- Layout responsivo para computador, tablet e celular.

**Observação:** o formulário apresenta uma confirmação no navegador. Nesta versão, as informações não são enviadas para um servidor nem ficam armazenadas após atualizar a página.

## 6. Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador. Também é possível utilizar a extensão Live Server.
4. Para testar, pesquise um conteúdo, selecione uma categoria e preencha o formulário.

## 7. Colaboração com Git e GitHub

O fluxo de colaboração proposto para o Grupo 6 está descrito em `docs/guia_git_github.md`. Cada integrante pode trabalhar em uma branch própria. Depois, deve abrir um Pull Request para revisão e integração na branch principal.
